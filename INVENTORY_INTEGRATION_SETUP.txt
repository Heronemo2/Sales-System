TEAM SALES <-> INVENTORY INTEGRATION

1. Product mapping
   Team Sales customer_order_requests.product_code = Inventory finished_goods.item_code
   Inventory product name = finished_goods.item_name
   Inventory stock = finished_goods.quantity

2. Current Team Sales behavior
   - Customer requests keep product_code and quantity in team_sales.
   - Sales checks inventory_management.finished_goods using item_code.
   - Quotation inventory_quantity is taken from finished_goods.quantity.
   - Re-check Stock uses the same source.
   - When an approved Sales Order is delivered, the requested quantity is deducted from finished_goods.quantity.

3. If Sales and Inventory are on the SAME PC
   Leave INVENTORY_DB_HOST as localhost.

4. If Inventory is on ANOTHER PC
   Radmin is only remote desktop software. It does not make localhost point to the other PC.
   In Team Sales config/inventory_db.php, set INVENTORY_DB_HOST to the Inventory PC's LAN IP, for example:

       $inventory_db_host = '192.168.1.50';

   Do not use the Radmin address as a database host unless it is also the PC's reachable LAN IP.
   The Inventory PC must allow MySQL/MariaDB remote connections and the MySQL user must have permission from the Sales PC.

5. Inventory API
   Inventory api/finished_goods.php now reads the actual finished_goods table and returns:
   product_code, product_name, quantity, stock_available, available, brand, category, size, unit, status.

6. Important
   The Inventory application also has a separate items/inventory warehouse model. This integration patch intentionally uses the finished_goods table supplied for Sales integration because that is the table whose quantity you specified as the authoritative finished-goods stock.
